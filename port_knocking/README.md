### Port Knocking Design

The port knocking system is implemented using python and utilizes UDP sockets, iptables, and multithreading. The system defines a default knock sequence, the protected SSH port, and a time window in which the sequence must be completed. The system works by first using iptables to block access to the port by default. Each port in the sequence has a UDP socket bound to it which allows the server to listen for knocks without interruption. When a knock is received the users IP and the timestamp are recorded, and old entries are removed to keep the timing window. Then the code checks if the most recent knocks match the sequence, and iptables is used to allow that IP to access the ssh port.
